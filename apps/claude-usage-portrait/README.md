# Claude Usage Portrait

Claude Code limits, machine-wide token history and live sessions, drawn for a Car Thing standing on its side.

A fork of [Claude Usage](https://github.com/JoeyEamigh/joey-bridgething-apps/tree/main/apps/claude-usage) by Joey Eamigh. The data side (the desktop extension and protocol) is his; the screens are laid out for a 480x800 portrait stage rotated onto the 800x480 display.

Settings: `rotation` picks which end the dial is on, and `invertDial` flips the scroll direction.
